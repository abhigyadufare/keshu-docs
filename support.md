# Support

## How to reach us

Use the [support form](https://form.jotform.com/262711699461465). Please include:

- Your first and last name, and your email
- Your store URL (for example, `your-store.myshopify.com`)
- The theme name (Keshu) and version (shown under the theme's name in Online Store → Themes)
- What happened, what you expected, and the page where it happens
- A screenshot or screen recording, if you can

You get an automatic reply when we receive your message. We reply within **two business
days**, usually sooner.

## What support covers

- Questions about Keshu's settings, sections, and blocks
- Help setting up the theme to look like a preset's demo
- Bugs in Keshu's own code. Critical bugs, like a broken cart or checkout button, are fixed as
  soon as possible, and fixes come to everyone in a theme update.

## What support doesn't cover

- Custom design or code changes, including fixing changes made to the theme's code
- Problems caused by apps or third-party code. We'll help find the cause where we can.
- Setting up Shopify features outside the theme, like shipping rates, payments, and markets.
  Shopify Support helps with those.

Before editing the theme's code, **duplicate the theme** (Online Store → Themes → ⋯ →
Duplicate) and edit the copy.
